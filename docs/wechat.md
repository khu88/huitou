# 微信助手：本机配置与使用

会投可把本地会议目录、账号收藏和截止提醒接到微信 ClawBot 文字会话。网页中的「微信助手」提供同一套指令的本机体验，先检查结果，再决定是否扫码绑定。

当前使用 Python 标准库实现的独立适配层，参考腾讯公开的 [openclaw-weixin 项目](https://github.com/Tencent/openclaw-weixin)及其[中文协议说明](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)。**不需要安装 OpenClaw、npm 包或配置付费大模型。** 查询采用确定性指令解析；不调用大模型生成研究事实，也不承诺任意自然语言都能理解。适配层不是腾讯官方插件；公开文档描述的是客户端行为，不是永久不变的服务端契约，真实账号兼容性需要扫码验证。

## 从本机体验开始

1. 在项目根目录启动完整后端：

   ```sh
   python3 serve.py --port 8766
   ```

2. 打开 [本机会投](http://127.0.0.1:8766)，进入「账号」，注册或登录自己的会投账号。
3. 进入左侧「微信助手」，在「本机体验」输入 `CVPR 截止`、`ICLR 论文` 或 `帮助`。示例按钮只填入文字，点击「查询 / 执行」才执行。
4. 试用 `收藏 AAAI`、`我的收藏`，确认账号中的结果。**本机体验中的修改会真实保存到当前会投账号**，并不是沙盒；但这些消息不会发送到微信。

可用独立数据库体验配置，避免混用已有账号：

```sh
python3 serve.py --port 8768 --database .local/wechat-demo/app.sqlite3
```

此时访问 [8768 本机实例](http://127.0.0.1:8768)。一个数据库内的收藏与提醒相互同步；不同数据库是独立实例。不要以多个数据库同时连接同一个微信助手。

## 绑定自己的微信

1. 在已登录的「微信助手」页面，点击「获取微信绑定二维码」。这个动作会连接微信官方服务；此前未绑定的本机查询不需要微信联网。
2. 用自己的微信扫码，并在手机完成确认。二维码在本机保留最多 5 分钟；如果微信要求验证码，按手机提示填写。失败或过期时重新获取。
3. 网页显示已绑定后，在微信 ClawBot 会话中发送 `帮助`，检查手机是否收到会投回复。第一条消息还会提供回复所需的会话上下文。
4. 检查手机聊天是否收到实际回复。网页只保留连接状态与必要错误提示，不展示发送记录。**接口接受不等于手机已经收到消息或弹出通知。** 请同时检查手机通知设置。

每个会投账号只绑定一个微信会话，本数据库内同一个微信身份不能同时绑定其他会投账号。服务只处理该次扫码绑定身份发来的直接文字消息；不会读取任意好友、群聊或历史聊天记录，也不会运行聊天中的 Shell 命令、代码或文件。

这里使用的是 ClawBot 助手通道，不是普通微信好友机器人。该账号能否扫码成功、会话是否可用及平台限制，以微信实际返回为准。腾讯的 [CodeBuddy 微信接入指南](https://www.codebuddy.cn/docs/ide/Platform-integration/weixinbot-guide)可帮助理解扫码到本地助手的使用方式，但其产品要求不能直接当作本项目的验收结果。

## 只接收 DDL 主动提醒

绑定后，默认开启文字收发，**主动提醒默认关闭**。在微信或本机体验中设置提醒，再打开网页上的「只推送 DDL 提醒」：

```text
提醒 CVPR 全文 提前7天
我的提醒
```

存在多个 Track 时，助手会列出编号且不保存猜测的选项，需要重新指定：

```text
提醒 ACL 第1轨 全文 提前1天
```

支持摘要、全文两类节点，提前量为 **7 天、3 天、1 天、3 小时、1 小时、5 分钟或截止时**。保存提醒会同时收藏该会议；仅收藏不会自动创建提醒。主动消息限已启用的 DDL 提醒，没有日报、资讯或论文推荐推送；用户主动提问仍会得到查询回复。

后台发送需要同时满足：本地 Python 服务运行、电脑未休眠、网络可用、绑定处于启用状态、DDL 推送开关开启、会议仍被收藏、提醒已启用且当前目录日期与保存日期一致。网页可以关闭，电脑和服务仍需运行。缺少有效会话上下文或微信拒绝主动消息时，提醒可能无法发送；**平台允许多长时间后主动发送，尚需真实账号验证，不保证离线必达。**

排程每约 2 秒检查一次，只处理本轮运行期间刚到点的提醒；延迟宽限最多 2 分钟。重新启动服务、恢复长时间休眠、刚启用推送或重新绑定时，不补发此前已过节点。日期变化会跳过旧排程并记录原因，需要重新设置。

每次发送前保存内部去重记录；失败或结果未知不会自动重试，避免不确定结果造成重复通知。这也意味着网络故障可能漏掉当次提醒，应检查连接错误提示与手机实际消息。日历导出仍可作为独立提醒方式；任何方式都应在提交前复核官网。

## 停止服务与恢复未完成命令

关机、睡眠、断网或结束 Python 进程后，微信功能暂时不可用；只关闭网页不会停止仍在运行的后台。重新运行同一份数据库后，已启用绑定会尝试恢复连接，并自动续处理**本机已接收、已保存但尚未完成的命令**。

本机先把入站命令持久化，再推进微信消息游标。收藏或提醒修改与回复正文在同一事务保存：若中断发生在处理后、发送前，重新启动会发送已准备的回复，不再次执行修改。延迟超过两分钟的已准备回复会注明原生成时间，避免将旧倒计时误认为当前结果。此处的恢复不需要你打开网页。

恢复仍有明确边界：

- 停机时尚未被本机收到的新消息，能否在上线后取得，取决于微信平台保留行为；不能承诺全部补回。
- 已经尝试发送、但因进程中断或网络超时无法确定结果的回复，不自动重发；请重新发送查询，避免重复回复或重复操作。
- 尚未执行且超过24小时的收藏／提醒修改会要求重发，不会突然改动之后的账号状态；只读查询可按当前目录重新回答。24小时是本项目防止旧操作影响新状态的规则，**不是微信官方会话有效期**。
- 会话凭证失效时，自动恢复可能失败，需要发送新消息建立上下文，或按错误提示重新绑定。暂停连接、账号停用或解绑会阻止恢复；解绑会删除关联的本地待处理命令。

DDL 推送保持前述不补发旧节点的规则，未完成聊天命令的恢复不等于补发停机期间的提醒。

## 常用指令

| 目的 | 示例 |
| --- | --- |
| 查看帮助 | `帮助` |
| 单场会议概览 | `ACL`、`查会议 ICLR` |
| 目录按学科和级别筛选 | `人工智能 A类会议`、`B类会议 第2页` |
| 截止与倒计时 | `WWW 截止`、`WWW 第4轨 截止` |
| 投稿与模板 | `AAAI 投稿`、`ICLR 模板`、`ACL 第1轨 投稿` |
| 历史证据 | `ACL 录用率`、`CVPR 参会` |
| 精选论文 | `ICLR 论文`、`ICLR 论文 第2页` |
| 即将截止 | `未来7天`、`未来30天`、`这个月截止`、`我的收藏截止` |
| 收藏 | `收藏 AAAI`、`取消收藏 AAAI`、`我的收藏` |
| 提醒列表 | `我的提醒`、`我的提醒 第2页` |
| 单条提醒管理 | `暂停提醒 ID`、`恢复提醒 ID`、`删除提醒 ID` |
| 停止全部提醒 | `暂停全部提醒` |

表中的 `ID` 要替换成「我的提醒」返回的完整 ID。取消收藏会暂停该会议的提醒；恢复已过期或日期变化的提醒会被拒绝。提醒最多 200 条、收藏最多 1000 条。查询窗口支持 1–366 天；每条回复最多 3000 字，较多结果通过页码或 Track 编号缩小范围。精选论文每会最多 10 篇，每页 5 篇，保留获奖和展示类别的原标签。

修改数据需要明确指令；未识别的修改表达会提示未执行，不会悄悄保存。一次消息只指定一场会议。图片、语音、视频和文件识别目前未实现；不含有效文字的消息返回帮助。网页版的木鱼声音、动画、账号密码和界面设置仍在网页中使用。

## 数据、隐私与停止连接

数据来自本地 `data/conferences.json`，不是每次聊天实时抓取。当前快照为 **2026-10-28**：390 场目录会议，12 场有详情，其余 378 场仍待补。录用率与参会政策显示明确的 2023–2025 年窗口；论文为已核验的 2025 年精选。返回来源和核验时间，未知字段不补造；投稿系统与官网冲突时保留说明。全目录可查不代表全部 DDL 都已补齐。

账号、收藏、提醒、微信绑定、内部去重状态与待处理命令共用启动时指定的 SQLite 数据库，默认 `.local/app.sqlite3`。绑定包含机器人令牌、扫码身份、会话上下文与消息游标；未完成命令还包含原指令和待发送回复正文，终态后清除这些正文。**这些数据未进行应用层加密**。新建数据库以私有文件权限创建；已有文件的权限不会被自动改写。不要分享数据库、WAL/SHM 文件、包含凭证的备份或扫码二维码；`.local/` 和数据库文件由 `.gitignore` 排除，但 Git 忽略不等于加密。

微信中的查询和回复经微信服务传输；本项目不会因此把本地目录或完整数据库上传。HTTP 状态响应不返回令牌、身份标识或会话凭证，进程日志也不记录聊天原文和这些凭证。本机体验的对话显示仅保留在当前页面内存；收藏、提醒的修改仍持久化到账号。

- 仅停止主动推送：关闭「只推送 DDL 提醒」，保留聊天查询能力。
- 暂停全部微信收发：关闭「接收并回复微信消息」，绑定和个人数据保留。
- 修改账号密码会撤销本机微信绑定，需要重新扫码。退出网页账号则保留已授权的后台连接，仍可处理微信查询和已开启的DDL提醒。
- 解除连接：点击「解除本机绑定」，删除本地绑定凭证、关联收件去重记录和待处理命令；收藏、提醒配置与内部发送元数据保留。
- 本地解除不是微信平台的令牌吊销接口；如要撤销平台端连接，还需在微信内按实际提供的入口解除或删除助手。取消一个尚未完成的二维码，也只取消本机等待流程。
- 退出网页账号不会停止已经启用的后台连接；停止本机进程可停止所有收发。再次启动同一数据库后，已启用绑定会恢复尝试连接。

备份前正常停止服务，再复制数据库所在目录，保留可能存在的 WAL/SHM 文件；或者使用 SQLite backup API。备份视为敏感账号资料，不应上传公开仓库。恢复到新机器后需要重新确认本机权限、网络与微信会话状态。

## 故障与验证范围

| 现象 | 检查方式 |
| --- | --- |
| 静态页面不能登录或绑定 | 运行 `serve.py` 的完整版本。GitHub Pages 和 `python -m http.server` 不运行 Python 账号与微信后台。 |
| 扫码过期或没有成功绑定 | 在会投重新获取二维码；确认微信完成了扫码与确认。接口或账号不可用不能由本机模拟测试排除。 |
| 已绑定却不能回复 | 先在微信发送 `帮助`，检查绑定是否暂停、是否显示会话失效或连接错误。令牌失效需解除本机绑定后重新扫码。 |
| 查询得到“详情待核验” | 目录已收录但详情未补齐；不是连接故障。 |
| 提醒保存了却没通知 | 同时检查双开关、收藏、启用状态、触发时刻、电脑与服务状态、连接错误及手机实际通知。 |
| 日期已变化或时间已过 | 重新查询当前 Track，设置未来仍可触发的提前量。不会自动补发。 |

命令、传输和调度可通过本地自动化测试验证。测试使用模拟微信接口与独立临时数据，**不能代替真实扫码、微信收发、主动提醒和手机通知送达验收**。本版本仍需用户自己的微信扫码后完成这些验证；不要仅因本机体验成功或接口返回接受，就宣称真实推送已经通过。

实现入口：[`wechat_commands.py`](../wechat_commands.py)、[`wechat_transport.py`](../wechat_transport.py)、[`wechat_service.py`](../wechat_service.py)、[`wechat.js`](../wechat.js)。完整本机启动和数据维护参见 [README](../README.md)。
