# 会投 · CCF 会议导航

面向科研工作者的响应式网页版：查询 CCF A/B/C 与补充 N 类会议，核对投稿 Track、截止日期、录用统计及精选论文，保存收藏和提醒，偶尔来解压室敲个木鱼。

当前以 **Web** 为主版本，使用 HTML/CSS/JavaScript、Python 标准库和 SQLite。原生手机工程已退出默认开发目录；不需要 Xcode、Android SDK 或 npm 安装即可运行网页。项目源码已公开，**代码许可证尚未确定**；图片、声音和第三方资料的来源单独列在 [素材说明](docs/assets.md)。

公开仓库：[khu88/huitou](https://github.com/khu88/huitou)，欢迎 Star、反馈和参与共建。每个页面都保留“加入我们的仓库”入口和“网页 / App 计划上线中，敬请期待”提示。此处指未来的公开服务与 App；目前交付的是本机运行的网页版。仓库地址及公开状态统一在 `site-config.js` 修改。

## 本机运行

在项目根目录执行：

```sh
python3 serve.py --port 8766
```

打开 <http://127.0.0.1:8766>，按 Ctrl+C 停止服务。需要可用的 Python 3；后端不依赖第三方 Python 包。账号数据默认保存到 `.local/app.sqlite3`，可用 `--database` 指定其他数据库。

服务只监听本机 `127.0.0.1`。这是可运行的本地账号系统，尚未部署公网 HTTPS 或邮件找回密码服务。可选微信助手通过本机服务向微信发起连接，无需公开本机端口。

## 功能与使用边界

- **会议导航**：A/B/C/N 分区、全部学科筛选、会议与 Track 搜索、收藏、截止日历；列表统计采用主 Track，详情分别展示摘要和全文节点。
- **可追溯详情**：举办日期与地点、投稿和模板链接、带时区的截止日期、录用整数比与百分比、精选论文、历史参会要求。旧届模板标明年份，未知字段不补造。详情中独立列出 CCF、CORE / ICORE、TH-CPL 的版本与来源。
- **真实账号**：注册、登录、退出、昵称与密码管理；账号收藏、提醒、设置和解压计数保存在 SQLite。会议浏览、解压室、服务与合作无需登录；收藏、提醒和微信绑定需要注册登录。访客的主题与解压计数保存在浏览器，旧访客收藏隐藏保留，登录后可手动导入。
- **设置**：亮色、暗色或跟随系统；标准、大、特大字号；显示时区、音效与减少动画。
- **微信助手**：账号内的本机指令体验、扫码绑定、会议/截止/投稿/模板/论文/录用统计/参会要求查询、收藏与提醒管理。网页和微信共用账号数据；默认关闭主动推送，开启后只尝试发送已设置的 DDL 提醒。无需安装 OpenClaw，不调用付费模型。完整步骤及真实微信验证边界见 [微信助手使用说明](docs/wechat.md)。
- **解压室**：参考用户提供图片的木鱼与橘猫 A/B 门、6 类 48 封 Accept 来信和情绪转译。A 门提供 ACL、CVPR、ICML、NeurIPS、WWW、AAAI、ICLR，保毕业 B 门提供 ICASSP，另有生活祈愿；图卡和飘字随选择同步。属于娱乐内容，不代表真实审稿结果；木鱼声音为合成音色，并非实物录音。音色和音量是当前会话选项，音效开关可随账号保存。

- **服务与合作**：API 中转、论文辅导润色、GPT / Muse / Grok 账号与额度会员服务，售后、AI 合作咨询、反馈和建议；统一通过页面邮箱联系。

### 提醒

可为已知的摘要、全文截止设置提前提醒。网页保持打开、浏览器支持并允许通知时，可以尝试显示浏览器通知；浏览器休眠、后台节流或关闭页面都会影响触发。

微信助手绑定并启用 DDL 推送后，由 Python 后台调度，网页可以关闭，但电脑、本地服务和网络必须保持运行。服务启动前或超过两分钟宽限的旧提醒不补发；日期变化会阻断旧排程。微信会话有效期及主动发送限制需要扫码后实际验证，**接口接受并不等于手机通知送达**。该渠道尚未完成真实微信收发验收。关机、休眠或停止进程后微信功能暂时不可用；使用同一数据库重启时自动续处理本机已接收的未完成命令，发送结果不明时不重复补发。停机期间的新消息是否保留由微信平台决定，详见使用说明。网页不展示微信发送记录。

也可导出包含 `VALARM` 的 ICS 文件，导入自己的日历应用。是否保留和触发提醒由日历应用、导入选项及系统通知设置决定，应在日历中确认。不要把“保存了提醒设置”等同于“通知已送达”。

### 公开版本与本地私有功能

公开版本包含普通账号的注册、登录、个人资料、收藏、设置、提醒、微信助手和公共木鱼累计。管理功能的界面、接口实现、操作命令与用户数量统计保留为维护者本地私有扩展，**不随仓库分发**。没有该扩展时，公开版本仍可独立运行。

仓库不包含真实账号、数据库、后台截图、运行日志或私有扩展。访客和普通账号不会取得本地扩展的脚本或数据；扩展文件也不属于静态资源白名单。公共木鱼累计与管理功能相互独立，关闭或不安装私有扩展不会影响敲击总量。

### 大家一起敲木鱼

木鱼页面同时展示个人计数和全站累计。新增敲击由访客与登录用户共同贡献，独立汇总到同一 SQLite 后端；刷新、请求重试或重复响应不会重复累计。已确认的累计重启后保留，注销账号不会减少匿名汇总。此功能从启用时开始，不导入过去的个人敲击记录。

客户端用随机计数标识暂存待同步次数，不附加账号身份；网络恢复后自动重试。清理浏览器存储会丢失尚未同步的次数；禁止本地存储时只能在当前页面保留待同步记录。统计服务不可用时显示未连接或上次确认值及状态，纯静态网页不会把本地计数冒充为全站累计。

**多端共用同一个后端才能共享总数。** 当前只验证本机服务；不同用户各自下载部署，统计会各自保存，不自动上传到维护者。未来网页与 App 需要接入统一服务，公网账号与统计部署仍需单独完成。统计是客户端上报的娱乐计数，已有基本限流，不保证识别真实人工敲击。

## 静态预览与 GitHub Pages

```sh
python3 scripts/build_standalone.py
python3 -m http.server 8767 --directory dist
```

打开 <http://127.0.0.1:8767> 查看构建版本。`dist/` 是生成目录，不提交到源码；修改界面、素材或数据后需要重新构建。

未来将 `dist/` 托管到 GitHub Pages 等静态服务时，可提供会议浏览、设置、解压、服务与合作及会议日历导出，**不能运行 Python/SQLite 账号服务，也不能提供后台远程推送**。收藏与提醒设置需要可用的账号后端；单独的静态页面不支持账号登录。完整公网账号版需要另行部署后端，并配置 HTTPS、Host/Origin、会话、数据库备份和运维；不要简单放开本机服务的监听地址。

GitHub 仓库提供公开源码；网页公共服务和 App 尚未上线。仓库公开不代表已部署账号、后台统计或微信服务。

个人维护不易，信息仅供参考，具体请以会议官网为准；会议分级请核对目录发布方。

## 数据维护与验证

在项目根目录运行：

```sh
python3 scripts/build_data.py
python3 scripts/validate_data.py
python3 scripts/audit_coverage.py
python3 scripts/build_standalone.py
python3 -m unittest discover -s tests -v
node --test tests/*.mjs
```

运行网页不需要 Node；最后一项使用已有 Node 执行 JavaScript 逻辑测试，无需安装 npm 包。Python 测试使用临时账号、数据库和端口，不写正式账号库。自动化检查不替代浏览器视觉、声音听感和真实通知验证。

`build_data.py` 从保存的核验输入生成快照，不联网采集。全目录扩展记录按学科保存在 `research/expanded-details/`，不会以空记录擦除旧详情。`audit_coverage.py` 生成 [逐会字段覆盖报告](research/data-quality-report.json)，区分三年统计齐全、三年作者政策齐全、论文精选及 Track 缺口；有届次资料不等于全部字段完善。原始网页/PDF 的 `research/evidence/` 缓存已排除于 Git，默认离线构建只需要经核验的事实 JSON。`python3 scripts/build_rankings.py` 从已保存官方来源和复核映射离线重建分级交叉表，再运行 `build_data.py`；来源版本、SHA-256 和匹配政策见 `research/conference-rankings.json`。校验包括目录数量、ID、来源、时区和日期顺序、模板年份、录用整数口径、论文数量及已知 Best 条目的保留。补充数据流程见 [贡献指南](CONTRIBUTING.md)。

## 目录

- `index.html`、`styles.css`、`app.js`：会议界面与交互。
- `portal.js`：账号与设置；`relax.js`、`relax.css`：解压室；`reminders.js`：网页提醒。
- `assets/`、`data/relax-content.js`：图片、合成声音和解压文案。
- `server.py`、`serve.py`：本机账号后端与启动入口。
- `data/conferences.json`：统一快照；`research/`：核验输入、来源和复现脚本。
- `scripts/`、`tests/`：构建、数据校验和测试；`docs/`：接口与素材说明。

本地数据库、运行日志、生成文件和任务交接记录不进入源码发布。安全边界与报告方式见 [SECURITY.md](SECURITY.md)。
